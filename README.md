# 说说你的Ping
为饥荒联机版而创作，你可以在[Steam创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=2997164720)中找到这个模组

## 如何安装？
在Steam创意工坊中订阅[说说你的Ping](https://steamcommunity.com/sharedfiles/filedetails/?id=2997164720)
接着在[饥荒联机版](https://store.steampowered.com/app/322330) -> 模组 -> 本地模组中开启 说说你的Ping/Say about your ping ，接着进入游戏

## 如何使用？
进入游戏后，屏幕右下角会显示你的Ping值，你可以点击它，点击后你的角色会在聊天中宣告你的Ping是多少，右键可以拖拽Ping值的显示位置

如需更改模组语言/宣告内容/显示文本：
请前往游戏主页面 -> 模组 -> 本地模组 -> 说说你的Ping/Say about your ping -> 配置模组 中更改
