# 说说你的Ping-服务器版
为饥荒联机版而创作，你可以在[Steam创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=2998347052)中找到这个模组

## 如何安装？
在Steam创意工坊中订阅[说说你的Ping-服务器版](https://steamcommunity.com/sharedfiles/filedetails/?id=2998347052)
接着在[饥荒联机版](https://store.steampowered.com/app/322330) -> 创建游戏 -> 创建新世界/选择存档 -> 模组 -> 服务器模组中开启 说说你的ping-服务器版/Say about your ping(Server)，接着进入游戏

## 如何使用？
进入游戏后，屏幕右下角会显示你的Ping值，你可以点击它，点击后你的角色会在聊天中宣告你的Ping是多少，右键可以拖拽Ping值的显示位置

若要查询其他人的Ping
只需要按下Shift+自定义快捷键（默认是`[`键）即可查询与自己在同一个世界的玩家的Ping
或者
使用聊天命令：#所有玩家宣告Ping（使所有玩家宣告自己的Ping） 、#@XXX Ping（指定一名玩家宣告Ping，例如：#@冰冰羊 Ping）

如需更改模组设置，请让房主在 `创建世界 -> 模组 -> 服务器模组 -> 说说你的ping-服务器版/Say about your ping(Server) -> 配置模组` 中修改设置
